# 0.6 桌面验证边界

日期：2026-10-17。

通过桌面控制工具选择本机游戏应用时，工具返回：

> The Mac is locked and automatic unlock could not unlock it. Ask the user to unlock manually.

因此本轮没有完成0.6的可见窗口操作、声音试听或真实游戏截图。没有绕过锁屏，也没有把源图、联系表或原生引擎日志标成实机截图。

已经完成的独立验证见NativeEnvironment_060_final.txt、SMAPILoad_060.txt、NativeTestResults.txt和StaticTestResults.txt：本机游戏实际加载六地点四季贴图，检查钓点、岸冰、抵达碰撞和独立天气。它们不能替代桌面游玩。

解锁后从工作区的北境航路.app启动专用预览存档，使用F6巡查六地点，试听环境声音、观察门口/桥/码头、人物比例和昼夜变化。正常游玩入口是启动北境航路·正常游玩.command。继续验证时不覆盖普通玩家存档。

当前可看的新版资源联系表为previews/ArcticAudit_after_060.png；最新已留存的真实桌面截图仍为0.4版本，仅作历史比较。
