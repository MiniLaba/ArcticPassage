# 北境航路：极地渔港 / Arctic Passage

**0.7.8 开发预览版；目标游戏 1.6.15，单人优先。** 小镇现名霜灯港 / Frosthavn。首批货错过鱼季后，可在K手记今日页按U改订当季鱼，保留三条鱼、400奖励和原生交货流程。全年可步行往返的苔原营地与可住宿研究站：冬季展示两座雪屋，其他季节换成帐篷。当前六个室外地区、三个室内，共36张四季地图；保留独立风潮、晴雨雪天气与岸冰对应水域。完整任务书尚未全部完成。

完整开发计划见 [docs/DevelopmentPlan.md](docs/DevelopmentPlan.md)：当前先补正常角色多日主线闭环，航空初访按最新要求提前；随后推进极地季节、冰钓/犬橇、完整人物/研究/节日和完整机场环境。2026-10-20本机主应用已调整为正常模式默认入口；开发预览改用独立命名入口，历史0.7.6安装包保持不变。本轮普通领票、完整飞行/跳过、步行入镇、旅舍保存冷重载及免费返乡已实测，见docs/AirTravel077.md。阶段实际证据见CompletionMatrix与DevelopmentStatus，不以计划代替实现。

去营地：镇区向北进入苔原，沿小路抵达中段木桥，向东跨桥后继续向东。红色研究站内左侧床铺可过夜；营地说明牌按 Enter 继续。按 K 查看六区域路线与五处自然笔记。雪屋目前只可从小路观察；新增基础雪原机场与航空入场。

本轮0.7.8：K会提示无竿时去渔港花25金币买训练竿；已有竿则显示投竿提示与本单鱼数。J可打开待领奖的原生任务页，再按Enter领取。正常新角色北极鳕实钓、出售85、旅舍春5保存/冷重载已通过，首批货毛鳞鱼仍未交齐，见docs/Onboarding078.md。

## 当前内容

- 按 K 打开霜灯港随身手记，1—3 或左右翻页：查看当前任务的下一步、季节钓鱼与住宿/返乡提示、六区真实路线及场景缩略图。自然笔记列出五处观察地景；亲自走近再按 R 记录，日期随角色在睡眠时保存，重复记录不累加、不授予渔获或金币。
- 首批货的旧鱼种不在当季时，今日页显示U改订按钮；有存鱼也可保留旧单继续交货。改订不交换物品或金币，已完成未领奖励不受影响。已完成实际按键改订、冬8原生保存和冷重载，见 docs/Shipment076.md；不代表正常新角色全流程已经通过。

- 三处柜台可按Tab启用键盘操作：方向键选择、Tab切商品/背包、Enter购买或出售，Esc关闭。实际售出风干鱼、鱼饵购买及食谱学习已实测；0.7.8正常角色买竿/售北极鳕后的交易保存冷重载通过，完整多日仍待。

- 0.7新增换季渔具保管：冰封或失去岸边通路的原版蟹笼连同渔获或未用鱼饵返回收购站蓝绿色箱子；箱满会等待腾位，不丢弃原笼。修复冬季第一晚误用秋季虾池。

- 霜灯港小镇、渔港、冰山峡湾、极地苔原、苔原营地、雪原机场，另有旅舍、收购站和营地研究站室内。地图共四季36份；机场64×40、峡湾72×56，其余室外64×48。

- 四道料理与付费食谱、外运配菜；旅舍右侧料理台提供原生烹饪界面。购买食谱、扣料与产物已通过原生API验证，普通按键打开厨房已实测。
- 艾达、米拉、罗安三名可社交居民，四方向行走帧、礼物偏好、日常/冬季/雨天日程，每人至少20条基础日常对话。
- 六步连续任务：入住旅舍 → 交三条当季鱼 → 40木材修棚 → 两块铁锭修船 → 到访峡湾 → 交大比目鱼。奖励通过原生任务日志领取。无期限、不可取消。
- 每日三种交货订单：在订单板用鱼换收据，金币即时到账；每种每日限一次。收据本身不值钱。

## 安装

先安装 [SMAPI](https://smapi.io/) 和 [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915)。运行模块需要 SMAPI 4.5.2+；本机验证 Content Patcher 2.9.1、游戏 1.6.15。内容包声明 CP 2.4.0+，旧前置版本未测试。

将安装包中的 `ArcticPassage` 和 `ArcticPassage.Runtime` 两个文件夹一同放进游戏 `Mods` 文件夹。正确层级分别是 `Mods/ArcticPassage/manifest.json` 与 `Mods/ArcticPassage.Runtime/manifest.json`。升级时保留存档，同时更新两个文件夹。通过 SMAPI 启动游戏。

本机游戏位置：
`~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Contents/MacOS`

本次开发另建了 `.development/TestGame` 独立副本，使用原游戏资源的链接，保留原游戏文件。开发工具和前置测试构建在工作区 `.development` 中，不属于内容包，不能移动后当独立游戏分发。

本轮主应用默认正常模式已实测；开发预览刚迁入独立PreviewMods目录，新的预览入口仍待桌面复验。16类说明的Enter继续已接入；镇/峡湾/苔原局部实测，其他新范围仍待；历史0.7.6压缩包未覆盖。

## 开始游玩

1. 进入存档，阅读月月鸟邀请信并领取随信的往返机票。站在农场邮箱旁可按 G 使用原生邮箱。钓竿可按探索需要携带。
2. 步行到巴士站，按 B 打开登机牌、Enter 登机；飞越冰峡湾并降落雪跑道，动画可按 Esc 跳过。沿机场南侧步道进入霜灯港。
3. 到广场西侧红房子入住；东侧蓝房子为收购站，朝东是渔港，朝北是苔原。
4. 第一份交货任务会按接取时的季节要求毛鳞鱼、大西洋鳕鱼或北极鳕。手持完整数量的一堆鱼，与艾达互动。任务日志写明目标。
5. 材料交给罗安。交货后睡一晚，检查来信与码头东端航线牌；大比目鱼需要钓鱼等级4。
6. 小镇东侧原返程牌免费接驳机场；机场 B、Enter 免费飞回巴士站。峡湾也始终有返程牌。

想做饭时，在渔港补给柜台购买食谱及配菜，回旅舍右侧料理台站在(20,8)朝上互动。港口蟹笼春夏秋产虾，秋季峡湾、冬季港口产雪蟹；放饵过夜，从岸上收取。冬季独立测试已验证正常过夜保存、重启与码头步行按键收取，见docs/WinterCrab063.md；其余季节及正常角色完整流程仍待验收。真实北方虾捕捞方式与本模组蟹笼不同，物品说明已注明玩法简化。

收购站柜台可售鱼；普通出货箱同样有效。渔港订单板通过原生交易界面结算，购买“收据”会消耗对应鱼并增加钱包金币。

## 源码与资源

`ContentPack` 是可编辑数据与美术内容包；`Code/ArcticPassage` 是小型SMAPI运行模块，用于安全回收跨季蟹笼、按真实日期选择笼鱼池、柜台键盘操作及限定场景夜景照明。运行模块引用本机游戏和SMAPI，自身程序集随安装包分发，不附游戏程序集。`tools/build_runtime.py` 通过工作区.NET SDK构建并暂存模块，打包前先运行；可用项目GamePath覆盖游戏路径。`tools/build_content.py` 结合 `tools/scene_maps.py` 和保留的 art/source 原图重建资源、TMX 与数据；需要 Python 3、Pillow 和 NumPy。营地重建另调用 tools/camp_maps.py 与 tools/camp_materials.py；航空内容由 tools/build_air_travel.py 生成；原图保持不变。tools/build_music.py使用FluidSynth、ffmpeg和另行安装的GeneralUser GS重建配乐，许可见docs/licenses。游玩内容包不依赖这些开发工具或Python。地图可直接在 Tiled 中打开；重建会覆盖手工修改，修改地图后应保留独立版本。

运行 `python3 tests/validate_content.py` 进行资源、地图连通性、任务与经济检查。`tests/NativeValidation` 使用本机真实游戏数据类和 SMAPI TMX 解析器；需要 .NET 6/8 SDK，可通过 MSBuild `GamePath` 指定带 SMAPI 的测试游戏目录。

本包不分发原游戏素材或游戏程序集。原创源码与素材采用 MIT 许可，前置模组版权分别归各作者，详见 [CREDITS](CREDITS.md)。
