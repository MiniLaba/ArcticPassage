# 换季渔具寄存 · 0.7设计与接入记录

岸冰改变可玩水域后，之前已放置的蟹笼可能落在不可接近的位置。保留原位会使渔具和笼内物品无法取回；不能通过把岸冰改成可步行来掩盖问题。

原生数据补丁不能枚举既存蟹笼、按附件状态转存并保证容量事务，因此按任务书15.5在Code/ArcticPassage加入项目自有SMAPI运行模块。地图、场景、对白、任务、海产与料理继续使用Content Patcher。运行模块只处理本项目四处室外地点中的原版710蟹笼，不触碰沙滩、农场等原版地点，也不替换游戏程序集。

## 玩家行为

岸冰封住旧笼位时，艾达把受影响的渔具带回收购站青色寄存箱。已经捕到的物品保留原数量和品质；尚未产出时退回未用的鱼饵。已有渔获时不重复退饵。开放水面且能从岸边操作的笼继续留在原处。

寄存箱为原生共享箱，采用青色外观，优先放在收购站(14,14)，被玩家物品占用时尝试临近三格，绝不覆盖已有物品。四格全部占用时暂缓并提示。共用仓储是合作农场设计；多人主机/客机实际同步仍需专项验收。

## 保全规则

- 从默认抵达点按当前地图地形检查连通岸边，原水格消失或不再邻接可达岸边的笼进入寄存。
- 保存/载入及换季后检查；转存仅由主机执行。源和目标都使用原生世界对象与箱子库存，不新增自定义存档类型。
- 先在独立箱子副本用原生堆叠规则试装；装不下时不动源笼、鱼饵或渔获。腾空寄存箱后再检查，防止默默丢物。
- 实际入箱成功后才移除原笼；重复检查不会重复添加。原版蟹笼的modData随返回渔具保留。
- 只有实际寄存发生时通知玩家，并寄一次说明信；日常无受困渔具时保持安静。
- 地图强制刷新限制为每地点每季一次，避免打开关闭普通界面就反复重载地图。

## 验证计划及状态

独立ArcticRecoveryQA从真实秋28日过夜到冬1日，准备三个峡湾笼（空、已投饵、已有两只金品质雪蟹）与十二个独立冬季审查确认的开放港口对照笼。比较寄存前后完整数量/品质，检查不提前回收、不退还已用饵、箱满保留原物、清空后恢复、重复检查、原版地点不受影响，以及原生保存和进程重启。

本文件目前描述设计与正在进行的测试，不以编译成功代替游戏验收。正式接入、安装包结构与最终证据应在测试后更新DevelopmentStatus.md。
