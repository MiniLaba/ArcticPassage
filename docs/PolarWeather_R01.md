# 极地天气与安全交通首版

日期：2026-10-26。该功能是R06天气系统的有限首版，不代表极光、完整气候模型或普通游玩验收完成。

天气由游戏年／季／日稳定派生，分为平静、强风浪和冬季白茫风雪。春、夏、秋只可能出现强风浪；冬季还可能出现白茫风雪。粗暴天气不会连续出现，以免玩家连续多日被锁在某处。这是为游戏节奏制定的固定规则，不是格陵兰气象概率，也不调用本机时间、天气API或游戏随机数。

K手记的“今日海湾天气”给出预报。强风浪与白茫风雪会暂停渔港至峡湾的外出航行；白茫风雪会暂停雪橇出发。处理使用地图上的具名动作，不更改全局天气、时钟、鱼池、角色位置、任务、物品或天气存档。峡湾返港动作无条件可用；岸上标记步道仍作为返程备选。风浪和白茫风雪通过运行时低密度斜向风线／雪粒表现，只绘制在八张模组室外地图。

地图内容源与运行时同时更新：`tools/build_content.py`、`tools/scene_maps.py`、`ContentPack/content.json`、`KeyboardRoutes.cs`和`SledTravel.cs`。旧返程位置与目标坐标不变，返回动作独立于出发动作和海况条件。
