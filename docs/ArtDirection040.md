# 0.4 美术修正

用户指出仍像只下小雪的普通小镇。此次同时修正局部画面与实际镜头，而不只依靠全图鸟瞰预览判断。

- 小镇与苔原春季去掉约大半鲜艳橙色花园式灌丛，改为大面积古老裸岩、低灰褐矮植被、地衣与受风塑形的积雪；道路由暖米色转为冷灰碎石。原0.3春季图在art/source/archive留档。
- 玩家在0.3峡湾观测台的实际画面看不到北端冰群。新增独立透明近景冰山图块放入Front，冰下水域按透明度排除，保持常用钓点开放；小镇同样增加港外近冰。
- 从沙滩与专用预览初到小镇的落点改成(36,23)，让海湾进入抵达镜头；地图主路、房门、北部/渔港连接保持原走向。
- 旅舍重做木墙、暖炉、厚毯、海图、靴架和住客物品；收购站重做秤台、冰箱、网绳、工具与整鱼处理台。家具逐格碰撞，原生出口与商店交互重新标定。
- 三名居民各有6表情肖像与16帧行走源图，服装/发型彼此对应，替换初版方块简稿。艺术仍需在实际对话与行走镜头检查；不以生成原图完成代替游戏内验收。

原图和完整内置imagegen提示词均在art/source、art/prompts。只对导出做尺寸/网格归一化，制作记录完整保留。当前修正不是“大奖级美术已经达成”的结论。
