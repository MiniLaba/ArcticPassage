# 晾鱼架与订单持久化（0.5实现，合入0.6）

晾鱼架是一种真正可制作和放置的原生机器，区别于地图里静态的晾鱼设施。配方为40木材、15纤维、1铁锭；修棚后的罗安图纸信提供配方，独立触发也覆盖已修棚的0.4保存文件。熏鱼机奖励保留，不重复制作同功能机器。

投入一条大西洋鳕鱼、毛鳞鱼或北极鳕，两个夜晚后收取风干产品。无需燃料，保留普通/银/金/铱星品质，基价为原鱼的1.4倍：168/91/119g。采用原生Data/Machines、BigCraftables、CraftingRecipes；不添加生产DLL。大比目鱼、红点鲑、木材与其他输入不接受。输出属原生工匠物品，原生职业、品质和售价规则仍适用；它并非每种职业组合都恰好比直接卖鱼多40%。

原生API已验证：制作材料准确扣除；三鱼×四品质输入、身份/品质保留、基价、无煤消耗；不支持输入不被扣除；加工不会立即完成。完整两夜计时（首夜未完成、第二夜可收取）、两种产品原生收取、机器/配方/产品保存与重载、图纸信学习均已通过。中间毛鳞鱼架保留待桌面实际收取。证据见NativeProcessing_050_final_engine.txt、NativeProcessing_050_reload_collect.txt、ProcessingSaveState_050.txt。

原生个人商店库存只保证同进程重新打开。实测0.4退出游戏、同日重载会刷新库存，因此0.5为每类订单写入带年/季/日的原生邮件标记，并由GameStateQuery排除当日已交类别。重载后0份、次日3份已通过实际进程重启回归。日期只影响日常订单，不改变主线任务要求；历史标记随个人保存文件保留，每游戏年最多336条。

素材由内置imagegen制作，源图art/source/drying-rack-master.png和dried-fish-products-master.png，完整提示词art/prompts/drying-rack.txt及dried-fish-products.txt。导出为32×32（两状态16×32）和48×16（三物品16×16）；alpha主体边界用于技术裁切，按比例缩放并对齐地面基线，原图不被改写。普通sprite_scale图是资源放大校对，不是实机。

测试方法分层：原生API集成验证覆盖实际游戏的制作、机器、交货、商店与保存逻辑，但不冒充玩家从零钓鱼、点击配方/订单和连续通关。真实桌面证据另行记录。
