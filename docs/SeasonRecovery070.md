# 0.7.0 秋冬衔接与渔具回收

2026-10-18，本机游戏1.6.15、SMAPI4.5.2、CP2.9.1。新增小型SMAPI模块：CP无法遍历并事务式移动旧存档蟹笼及其内容，任务书15.5允许在数据包能力不足时使用C#。内部内容标识保持兼容；正式安装需同时放入内容包与ArcticPassage.Runtime。

## 实际发现与修复

秋28通过正常旅舍睡眠进入冬1，原生蟹笼日更先于CP的季节令牌刷新，10个港口对照笼中4个仍产秋虾。失败日志NativeRecovery_070_before_season_fix.txt保留。运行模块在GameLocation.GetCrabPotFishForTile返回处校正本模组两个海区的ap_shrimp_/ap_crab_类型，直接读取当前真实季节；保留外部类型，不改变原版地点、原生随机数、鱼饵和收获机制。

修复后同一独立秋28基线重测，冬1港口10笼结果4雪蟹、6垃圾，无虾。所有笼经过原生placementAction与鱼饵投入，不是写入预设渔获。峡湾三个状态用于回收：投野生鱼饵、预置2只金星雪蟹、空笼；其中金星堆叠是明确的保存夹具，不能算真实钓获。

- 箱内数量/品质与移动前快照严格一致，2只金星雪蟹保留；已捕获笼不重复退饵。
- 用满箱夹具模拟容量不足，原笼与未用高级鱼饵保持；腾位后只回收一次，退1份未用高级鱼饵。
- 原版沙滩对照笼不动；重复执行没有复制物品。所有失败均保留源物体。
