# 0.7.4：把海湾变成可读的日常旅程

## 实现

游戏内展示名称统一为「霜灯港 / Frosthavn」。旧的 ArcticPassage_* 地点、任务和物品 ID 不变，LumenhavenTheme 音轨 ID 仍保留；显示文本的替换在生成器 tr 函数统一处理，不去改玩家的保存文件。

K 打开随身手记；1/2/3、左右或 Tab 翻页，上下选择笔记，R 记录眼前地景。今日目标读原生 questLog 与建设 mailReceived 标记，提示任务日志领款、实际交货数量、隔夜维修、所需钓鱼等级；路线页读实际四区步行/船线与当季场景缩略图，室内定位到镇区；手记不提供瞬移。

四个落点：镇区(25,24)、港口(32,11)、峡湾(35,31)、苔原(25,4)。角色须在对应地点、距锚点不超过两格，才能新增自己的观察记录。仅将首次日期/时间写入当前农夫 modData，重复不覆盖首次时间；原生睡眠保存，不主动强制保存，不授予鱼、钱或道具。其他模组地区和未访问霜灯港的原版角色不会被 K 接管。没有全服共享奖励；多人仍待真实联机验证。

## 真实验证与边界

本轮使用已有独立 ArcticFlowQA 副本（先前完成设施解锁），春7/1683 开始。原 ArcticQA 春6/1618 未改写。这不是正常新角色全流程证明。

实际按 K 打开三页、数字键切页；旅舍远程 R 保持0/4。使用 QA F6 只定位到既有场景入口，再按普通方向键走到港口(33,12)、峡湾平台、镇区(26,23)，实际 R 记下 harbor/ice/rock 三项；港口重复 R 保持1项且首次时间不变。三项首次时间为春7 10:10、11:50、12:50。沿普通按键路线从镇区进入旅舍、绕桌到床位，原生 Y 确认睡眠，保存为春8，钱包仍1683。证据 NativeGuide_074_record_sleep.txt、GuideSaveState_074.json、InGame_Guide_*_074.jpg。F6场景定位不算实际乘船/自然徒步跨区；本轮苔原记录还未实际走到北端，四处四季可达性由静态检查覆盖，不能混为四季实走。
