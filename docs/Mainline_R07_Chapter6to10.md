# R07 后半主线候选（2026-10-27）

## 内容流程

1. 深水交货后，以三类动物、一处地貌、鲸影记录为条件收取调查袋，交给莱文。
2. 社区屋开章，独立剧情公告板接20纤维捐交单，再接原生实际竿钓订单。两单不占普通周单名额；超时可按周重接。
3. 在苔原实际与米拉交谈，显示路线安全建议；一次性增加150友情，并寄出挡风屏风。
4. 到营地完成三层雪块课程；在当日开放的准确3×2冰洞抛点实际竿钓。原生成功捕获回调和新增／堆叠入包同时成立才记账，之后寄出雪屋模型。
5. 从港口、峡湾、苔原溪流任意两个不同水域取得并收下竿鱼；在晾鱼架加工毛鳞鱼或两类鳕鱼，用加工品在既有订单柜台完成首次出口交易。
6. 原生出口回执开启加工品日单和每周出口箱；缓存菜单以持久回执拒绝重复付款。
7. 交诺拉10木材作提灯木杆；18:00—24:00进镇触发六居民结尾。演出使用冬季镇区临时地图、原灯源与极光色带，实际日期／季节不变。原生结束／跳过标记才完成最后任务，日常系统继续开放。
