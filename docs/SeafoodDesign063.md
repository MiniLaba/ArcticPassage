# 海产与料理设计 · 0.6.3

本轮按任务书补齐金红鱼、北方长额虾、雪蟹与四道料理，九种海产重做独立图标。普通钓竿鱼与蟹笼鱼分开，不把不同北极海区视为同一生态系统。

金红鱼采用Sebastes norvegicus，夏秋在峡湾深水航线出现，钓鱼等级2以上、难度60、基价170。该物种的北大西洋分区见[ICES金红鱼资料](https://standardgraphs.ices.dk/ViewCharts.aspx?key=22441)。鱼种、海区原型有资料依据，季节、等级和概率是游戏设计，不是现实捕捞建议。

北方长额虾Pandalus borealis在港口春夏秋的独立蟹笼池出现，基价110；现实北大西洋渔业常在150—600米软质海底作业，见[加拿大渔业与海洋部管理资料](https://www.dfo-mpo.gc.ca/fisheries-peches/ifmp-gmp/shrimp-crevette/shrimp-crevette-2018-002-eng.html?wbdisable=true)。本模组岸边蟹笼是简化，已写入物品说明。

雪蟹Chionoecetes opilio在秋季峡湾、冬季港口的独立蟹笼池出现，基价235；小圆甲、长细足，避免误画成多刺帝王蟹。形态与区域差异参考[加拿大渔业与海洋部雪蟹资料](https://www.glf.dfo-mpo.gc.ca/en/integrated-fisheries-management-plan-snow-crab-southern-gulf-saint-lawrence)。

蟹笼使用原生投饵、过夜、收取和垃圾几率。自定义类型ap_shrimp_季节、ap_crab_季节只分配给本模组水域，不给原版海洋添加虾蟹。港口与峡湾分池；非目标季节仅有垃圾。尚需四季实际地图放置、收取、跨季与存档的桌面验证。

增益时长均为240游戏分钟，采用原生食物增益规则，不叠加自定义永久属性。食谱由港口补给柜台各450金币出售，已学食谱应退出供货；外运配菜限量5份/天，蟹笼需钓鱼3级、每天最多3个。旅舍右侧料理台(20,7)提供原生Kitchen，站在(20,8)面向上互动。也可使用玩家已升级农舍的厨房。
