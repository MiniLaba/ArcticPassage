# R05 野生动物与极地科研记录

更新：2026-10-26。该记录描述已经写入工作区的代码与静态验收；**不代表已在普通存档里逐项触发**。

## 已实现

随身手记现有七页导航；其中路线、地景、动物、极地现象和研究账目组成R05使用的页面，地景页保留原有五处记录点。本次研究奖励门槛沿用前四处（镇区岩岸、港口、峡湾、苔原），不要求营地观察替代原任务书要求。

动物页包含八类陆地／岸边观察对象和两类远海科研记录：

| 对象 | 场景与窗口 | 设计约束 |
|---|---|---|
| 北极熊 | 冬季白天，冰川选定日 | 只能在安全观景台记录；出现时提示危险并暂停经过冰川的犬队出发 |
| 北极狐 | 苔原，四季白天 | 远景观察，不喂食、不捕捉 |
| 格陵兰驯鹿 | 苔原，春至秋季的选定日 | 远距离观察 |
| 环斑海豹 | 峡湾岸边，春／秋／冬白天 | 从安全岸台观察 |
| 海象 | 港湾外水域，夏／秋选定日 | 仅岸上观察 |
| 雪鸮 | 北部苔原，秋／冬白天的选定日 | 不靠近、不打扰 |
| 三趾鸥 | 外港，春至秋白天 | 局限在沿岸，不把海鸟声放进内陆环境 |
| 犬队 | 修好犬舍后、冬季雪橇山路 | 工作犬只作伙伴／交通，不引入饥饿、受罚或驯养系统 |
| 座头鲸 | 夏季峡湾选定日 | 远海鲸背／喷气的科研观察，不是鱼获或商品 |
| 格陵兰鲨 | 秋冬峡湾深水选定日 | 水下剪影科研记录，不是鱼获或商品 |

十个对象由代码绘制双帧、透明小图集渲染。对象出现按地点、季节、时段及可预测的游戏日历窗口检查；这些日期是为了让玩家可寻找、可记录的游戏规则，不声称代表真实种群数量或野外出现概率。记录日期和时刻写在玩家原生 `modData` 中，随存档保存；重新按记录键不会重复授予记录。

极地现象页加入四项可记录内容：夏季长日照时的午夜太阳、冬季中午蓝色暮光、晴朗冬夜的极光、预报白茫风雪。它们分别读取既有极昼光照与天气规则；极光只在冬季选定的平静日、20:00后、峡湾／冰川显示。系统不改原版时钟、季节长度或睡眠。条目文本明确表示观测没有额外魔法增益。

研究账目从存档实际状态读取九种目标鱼获、八类动物、四类现象、四处地景，以及至少三种不同的研究订单交样记录。鱼获读取原生 `fishCaught` 或交样后的日期记录；交样数据只在原生订单成功扣鱼后写入。符合条件后，主机玩家收到一次原生邮件，获得可室内摆放的野外图谱展示架；同一奖励在邮箱／已收信记录中做防重复判断。

真实生态背景核对见[RealWorldReferences.md](RealWorldReferences.md)。资料用于物种、栖息地和文字背景；像素出现点、日历窗口、画面比例和研究门槛属于游戏设计。
