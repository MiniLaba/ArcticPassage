## 项目审计

当前公开版本0.7.10。来源：ArcticPassage/docs/DevelopmentStatus.md，官网src/ExpeditionContent.ts，以及AirTravel.cs、SledTravel.cs、PolarPhenomena.cs、WildlifeSightings.cs等实际实现。

核心识别：月月鸟邀请和航空抵达、北极岩岸/深水/彩屋、实钓与加工、犬橇与冬营、六位邻居、极地光与暖窗。

项目素材目录本轮没有发现足够的原始游戏录像；现有旧动态记录为InGame_Airline_flight_native_077.gif（低帧）。已有MP4是上一版渲染宣传片，不计入实录库存。此前桌面日志存在输入失败记录，本轮没有验证当前录屏/操作通路，不能提前宣称可以稳定实录。正式制作前必须完成一条可回放、连续运动、声音可核查的真实游戏录制样段。

上一版制作问题：静图占比太高；画面运动大多为缩放平移；声音沿用原网站动机和通用MIDI音色；没有主观听感把关。既有交付文件保留归档，新片重新建立方向与声音。

## 四个方向

### A · 北方，为你留灯（主推荐）

主命题：遥远的北方，会慢慢成为自己的日常。

60秒结构：风雪与单一暖点0–8 → 月月鸟抵达8–16 → 实录钓鱼/加工/往来16–40 → 实录居民与夜港40–54 → 暖灯品牌54–60。

原创动效：霜纹在黑蓝玻璃上真实生长，裂开为航线；航线用同一条曲线匹配到实录中的鱼线、犬橇轨迹和港口灯路；最后由一扇暖窗收成霜灯港字标。剪辑以运动方向、光的位置和声音匹配，不做截图轮播。

实录承担约65–75%。居民以实际走动、转身和交谈进入，不采用肖像卡片依次出现。

音乐：新选有完整情绪弧线的现代室内乐/电影民谣，清晰主旋律、拨弦、真实质感的独奏弦乐、后段轻打击。冷开场留空间，日常段展开，结尾有完整收束。先听样段再定编配，不从原GM音色继续调整。

适合：首支正式品牌预告片。风险：必须拍到足够有情绪的互动与夜景；不宜被节日/功能清单塞满。

### B · MM027：下一站，霜灯港

主命题：一张机票，把日常送到北极。

60秒结构：3D登机牌/航班动字0–10 → 折纸地形与航线10–18 → 原生飞机降落实录18–26 → 海港日常实录26–48 → 航空标识与目的地48–60。

原创动效：纸张弯折、压印、打孔和阴影；航线穿过折纸岩岸，票面目的地逐步变为通往游戏实录的画面开口；螺旋桨转动匹配抛竿圆弧，再以地面滑行方向匹配犬橇实录。航空主题动画与游戏实录有明确画面语言差异，不将CG地形冒充游戏地图。

实录约55–65%。原创航司动态图形为识别，不重用上一版机窗慢推开场。

音乐：清爽的旅行流行/独立器乐，尼龙弦或轻巧拨弦主导，约100BPM的松弛节奏，有可记忆的短旋律。纸张、登机提示、引擎进入声画节拍，声音不做机场广播轰炸。

适合：突出月月鸟航空、登机牌和小镇整体品牌。风险：包装太长会让人记住航空而忽略游戏，必须留足完整玩法录像。

### C · 先过好，北方的今天

主命题：在这里，做的小事也会让人想留下。

60秒结构：原生实录抛竿/咬钩0–9 → 鱼获/交货/加工9–25 → 遇人/步行/犬橇25–43 → 黄昏与夜港43–55 → 简洁品牌55–60。

原创动效：从真实浮漂激起的圆波引出手绘水纹字效；水纹匹配蒸汽，木槌落下匹配鼓点，犬橇滑行轨迹写出章节短语；文字沿场景中的实际方向进入，少量、有因果，不悬浮堆卡片。

实录约80–85%。保留有节奏的连续操作，单一玩法镜头给足观众看清动作和结果的时间。录像来源与效果保持真实，不以影片中的补画制造游戏功能。

音乐：先以水、雪、木板、门和引擎的实际声音建立节拍，再进入明亮而温暖的民谣/室内流行编配。主旋律不应被音效冲击淹没。

适合：最直接建立玩家信任、展示游戏可玩性。风险：原生动效和画面质量会直接决定片子的上限，需要更仔细的拍摄调度。

### D · 霜与灯

主命题：冷的材质，暖的生活。

60秒结构：冰晶微观0–9 → 霜纹和折射引出实录9–20 → 真实海港/居民/犬橇20–45 → 原生夜景45–54 → 凝霜字标与暖点54–60。

原创动效：具有厚度和景深的冰体、受光霜枝、体积雾、透射和反射；实录作为连续播放的视频嵌入折射与遮罩，而非冻结成冰中的图片；尾段霜层剥落留下暖色字标。动效有物理逻辑，避免随机粒子和泛用科技光线。

实录约55–65%。片内清晰区分主题动画与实际游戏，原创视觉不暗示原版不存在的3D玩法。

音乐：克制而有张力的氛围电子/新古典混合，处理过的弓弦、深而轻的低频脉冲、短旋律动机。中段增长，结尾释压。没有伪造因纽特/萨米等传统文化音声。

适合：视觉识别最强、偏艺术品牌电影。风险：材质与光线若不精细很容易显廉价；应先做短段验证，而不是用现成冰块模型铺满全片。

## 所有方向共用的执行门槛

- 实录先行：独立录制用存档，保护玩家存档；先完成10–15秒实录通路测试，再录镜头表中的连续素材。拍摄可调度时段/天气/机位，功能动作与结果要在游戏中实际发生，不将拍摄条件调度声称为普通游玩通关。
- 配乐先行：提供三款实际可播放的15–20秒候选，与选定方向对应；来源和授权可追溯。不以BPM、音轨或响度参数替代听感选择，不承诺尚未获得的高质量采样音源或成品曲授权。
- 样片先行：以选定方向制作15–20秒“原创动效 + 实录 + 新音乐”的完整样段，方向获认可后再进入整片。
- 最终所有实际游戏段落只用原始录制视频，不使用游戏截图、截图GIF、静态地图推拉或浏览器仿制的游戏动画填补空缺。
- 主片以游戏体验为中心，中文主导，文案精简；技术和来源记录只放工程文档。
- 这轮四张图片仅为原创分镜/构图符号稿，不是最终材质或游戏画面；由代码绘制，没有生图。
