# Frosthavn · 霜灯港

A northern chapter for Stardew Valley. Official showcase for the unofficial Arctic Passage mod: code-drawn winter atlas, day/dusk exploration, Yueyueniao airline invitation, gameplay captures and installation guide.

## Development

Run npm ci, npm run check, npm run test, and npm run build. This repository retains the actual Lovable TanStack Start framework and connects to project 4d283a60-7681-4f56-90e8-65648e0bdf55. Pushes to main synchronize with Lovable; publish changes separately to update the live website. Do not rewrite published Git history.

Page content and release links: src/components/frosthavn/content.ts. Styles, sprites, fonts and panorama are hosted locally; no backend or AI service is required. Keep the Free-plan platform badge.

Mod download and install guide: https://github.com/MiniLaba/ArcticPassage/releases/tag/v0.7.9 . This is a 0.7.9 development preview, not the completed expansion. The page explicitly marks unfinished scope and isolated gameplay QA.

See CREDITS.md for asset provenance and font licenses. No personal passenger data, game saves, SDK, game files or private account diagnostics are included.
