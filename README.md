# 霜灯港 / Frosthavn

《星露谷物语》电脑端单人扩展。玩家乘月月鸟航空到达一座北极港镇，从出门、买卖、钓鱼和归家的日常逐步走进外岛、苔原和冬季犬队路线。

[焕新版地图集](https://frosthavn-siming.lovable.app/#atlas) · [0.7.10 玩家安装包](https://github.com/MiniLaba/ArcticPassage/releases/tag/v0.7.10) · [中文安装指南](INSTALL.zh-CN.md)

## 焕新版开发设想

先在 **3 × 3 公里、1:1 的 Blender 母场景**中确定海岸、地貌、设施、四季与天气，再把经人工审阅的参考转成星露谷中可复用的像素组件。游戏保留紧凑的步行尺度，门、台阶和道路要同时支持玩家与居民移动。角色走路、居民日程、庭院作业和剧情事件应当在同一条日常路线里发生。

港镇沿天然海岸展开。机场设在镇西现有台地，远离城区。主路承接清雪和交通，小径随积雪改变。北界冰川、外海冰山、种子库和季节冰屋各有独立的地形依据与游线。四类地表在地面横向交错。春季融雪、秋季红金苔原、冬季极夜、暴雪和极光先在 3D 场景中看尺度、色光和可读性。母场景也提供网站和宣传片的地形与取景参考。

**当前进度** · 地形、设施落位、四季、机场及极夜母场景已有可编辑稿。Tiled 里已有分区和平面草图。网站工程包含四季与第一人称浏览。焕新版尚处在从地图设计向游戏资产过渡的阶段。下表的后续实机内容以实际通过的切片为准。

## 接下来怎么做

| 顺序 | 工作 | 可交接的结果 |
| --- | --- | --- |
| 1 | 对照 3D 母场景复看港街、机场、主要动线和四季变化，以固定机位记录美术修改 | 人工选定的场景与色光基准 |
| 2 | 先做一屏灯市港街。制作可复用的岩岸、石路、木栈桥、门廊、窗灯与系缆柱，绘制罗安四向步态，接入艾达的秤台 | 一屏实机地图、组件源稿、走路与遮挡审阅 |
| 3 | 接通旅舍、灯市、收购站和码头。串起两人日程、玩家钓鱼卖鱼、修船线索和回家过夜 | 一段从早到晚的可玩切片，走完整段后复看美术与实际落脚点 |
| 4 | 沿机场进镇、修船去峡湾、驿路去郊外三条线路扩建，再接其余居民、室内、主线及节庆 | 可逐条走通的分区，按实测工时安排下一批 |
| 5 | 从审核通过的母场景导出网页和宣传素材。玩法镜头取自实机 | 网站资产、成片与注明来源的取景素材 |

每轮美术可以反复。功能核对跟着改动走，调整门、碰撞、日程、季节路径或者交互时，走一次受影响的路线。第一段以「出门 → 码头 → 钓鱼卖鱼 → 回家过夜并读档」做集中实机验收。

## 当前可玩版 0.7.10

下载 [ArcticPassage-0.7.10-install.zip](https://github.com/MiniLaba/ArcticPassage/releases/tag/v0.7.10)，将其中的 `ArcticPassage` 和 `ArcticPassage.Runtime` 同时放入游戏的 `Mods`，并安装 SMAPI 与 Content Patcher。启动后查看月月鸟邀请信，到巴士站按 B、Enter 出发。

现有版在 macOS 上以游戏 1.6.15、SMAPI 4.5.2、Content Patcher 2.9.1 实测。完整普通存档流程和其他系统的实机范围详见[玩家状态说明](docs/PLAYER_STATUS.md)、[Windows 兼容范围](docs/WINDOWS_COMPATIBILITY.md)及[更新记录](CHANGELOG.md)。
